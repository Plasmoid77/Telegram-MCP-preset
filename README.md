# Telegram-MCP-preset

Пресет поверх [chigwell/telegram-mcp](https://github.com/chigwell/telegram-mcp): превращает
обычный Telegram-аккаунт в ИИ-ассистента, который сам отвечает в личке и в выбранных группах,
работает секретарём владельца и выполняет его поручения по Telegram.

Сервер telegram-mcp **не изменяется**: он ставится из оригинального репозитория на проверенном
теге (`v3.3.22`). Здесь лежит то, что построено вокруг него: настройки сервера, автоответчик
(диспетчер, промпт, защитные хуки), юниты systemd, установщик и полная документация, включая
историю того, что ломалось и как это чинили.

> Аккаунт, на который ставится пресет, будет управляться ИИ. Используйте отдельный (запасной)
> аккаунт, а не основной.

## Что получается

- **MCP-сервер Telegram** как постоянный сервис на `127.0.0.1:8765/mcp`: одна сессия Telegram на
  всех клиентов (Claude Code, Codex, любой MCP-клиент), все 153 инструмента.
- **Автоответчик**: на каждое входящее обращение запускается один короткий запуск агента с чистым
  контекстом. Он читает переписку через MCP и отвечает.
  - **Личка:** отвечает всем.
  - **Группы:** только те, что владелец разрешил (папка Telegram, бот правит её сам по просьбе),
    и только когда к боту обратились: reply, @упоминание или слово-обращение.
  - **Два режима.** `owner` — владелец, все инструменты, поручения. `guest` — все остальные:
    только текущий чат, ограничение на уровне кода.
  - **Секретарь:** важные чужие обращения пересылает владельцу.
  - **Память:** «запомни…» от владельца → файл `memory.md`, подмешивается в каждый запуск.
  - **Большие задачи:** прочитать весь форумный топик (сотни сообщений) и выложить сводку.
  - **Голосовые и кружки:** расшифровывает локально, на этой же машине (GigaAM-v3 E2E RNN-T
    в полной точности или любая модель onnx-asr).

- **Персона по умолчанию** — «Нейросетевой Doom bot» в манере Джарвиса из «Железного человека».
  Имя меняется в `config.env`, характер — в `prompt.md`.

## Как устроено

```
 Telegram ◄── MTProto, одна сессия ──► telegram-mcp.service (upstream, HTTP 127.0.0.1:8765/mcp)
                                          │ лента входящих (личка) → incoming_feed.jsonl
                                          │ wait_for_events (группы), list/get_folder
                                          ▼
                              telegram-agent.service (dispatcher.py, только stdlib)
                                          │ на каждое обращение:
                                          ▼
                 агент: claude -p + prompt.md + memory.md + хуки guard.py / reflow.py
```

Подробно — [docs/PRESET.md](docs/PRESET.md).

## Быстрый старт

```bash
git clone https://github.com/Plasmoid77/Telegram-MCP-preset
cd Telegram-MCP-preset
./install.sh
```

Дальше по [docs/INSTALL.md](docs/INSTALL.md):
1. Впишите `api_id`/`api_hash` и войдите в Telegram в **своём** терминале. Строка сессии не
   должна проходить через чат с ИИ.
2. Заполните `~/.local/share/telegram-agent/config.env`: ваш id, id аккаунта бота, имена.
3. Войдите в Claude Code.
4. `systemctl --user enable --now asr-server telegram-mcp telegram-agent`.

Поручить установку ИИ-агенту можно: дайте ему этот репозиторий и [AGENTS.md](AGENTS.md). Секреты
и вход в Telegram человек делает сам, агент лишь говорит, где и что ввести.

## Агент (harness)

Сейчас автоответчик запускает **Claude Code** (`claude -p`). Он опирается на его возможности:
список разрешённых инструментов на запуск, PreToolUse-хук, блокирующий вызов по аргументам, и
PostToolUse-хук, подменяющий результат.

Открытые агенты вроде Qwen Code и Hermes Agent с моделями DeepSeek/Qwen умеют это лишь частично.
Как сделать пресет независимым от агента — в [docs/HARNESSES.md](docs/HARNESSES.md).

## Проверено

- **Окружение:** 2026-11-16, Arch Linux, systemd --user, Python 3.14, telegram-mcp `v3.3.22`,
  Claude Code 2.1.325, модель Claude Sonnet 5.5.
- **Вживую:** личка владельца и гостя; группы (reply, @упоминание, слово-обращение, гость);
  управление списком групп из лички; чтение топика на 322 сообщения и публикация сводки;
  память; блокировки guard. Список и история — в [docs/PRESET.md](docs/PRESET.md).
- **Тесты:** `install.sh` в чистой домашней папке; тесты хуков.
- **Не проверено:** другие агенты и модели.
