# Telegram-MCP-preset

[English](README.md) · Русский

Пресет превращает обычный Telegram-аккаунт в ИИ-ассистента. Он отвечает в личке и в выбранных
группах, сообщает владельцу о важных обращениях и выполняет его поручения в Telegram.

При чистой установке установщик берёт [chigwell/telegram-mcp](https://github.com/chigwell/telegram-mcp)
из исходного репозитория, по умолчанию на проверенном теге `v3.3.23`. В этом репозитории
находятся автоответчик, настройки сервера, локальное распознавание речи, юниты systemd и гайды.

> Используйте отдельный Telegram-аккаунт. ИИ будет действовать от его имени.

## Что умеет

- **Общий MCP-сервер Telegram.** Одна сессия Telegram обслуживает совместимые MCP-клиенты по
  Streamable HTTP на `http://127.0.0.1:8765/mcp`. На этом локальном адресе доступен каталог
  инструментов upstream.
- **Автоматические ответы.** Диспетчер собирает подходящие входящие сообщения в пачку и запускает
  агента с новым контекстом без интерактивного интерфейса. Ассистент отвечает людям в личке, а в
  разрешённых группах реагирует на ответ на своё сообщение, @упоминание и слова-обращения.
  Владелец может попросить ассистента изменить Telegram-папку, которая задаёт список групп.
- **Доступ владельца и гостя.** Владелец может поручить ассистенту управлять чатами и публиковать
  сводки длинных форумных топиков. Гостю доступен текущий чат. Он может передать уведомление
  владельцу или переслать сообщения из текущего чата в настроенный чат для уведомлений.
- **Память и персона.** Владелец может сохранять инструкции в `memory.md`. Персона по умолчанию —
  русскоязычный «Нейросетевой Doom bot» в манере Джарвиса. Имя задаётся в `config.env`, язык и
  стиль — в `prompt.md`.
- **Локальная расшифровка.** Пресет расшифровывает голосовые и кружки на той же машине через
  onnx-asr. Модель по умолчанию — GigaAM-v3 E2E RNN-T в полной точности.
- **Обновления upstream.** Включите `telegram-mcp-update.timer` для еженедельных уведомлений
  о релизах. Обновление запускается вручную через `update_mcp.py apply` с проверкой и откатом при сбое.

## Как это работает

```text
Telegram ⇄ telegram-mcp.service (одна сессия, локальный HTTP)
             │ лента лички и события чатов
             ▼
           telegram-agent.service (dispatcher.py)
             │ новый запуск агента на каждую пачку подходящих сообщений
             ▼
           Claude Code, Codex, OpenCode или внешний раннер
```

Основной MCP-сервер и автоответчик работают как пользовательские службы systemd. Расшифровку
выполняет локальный сервис ASR. Подробнее в [описании пресета и истории изменений](docs/PRESET.md).

## Быстрый старт

Нужны Linux с пользовательскими службами systemd, Python 3.10 или новее, `git`, `uv` и `ffmpeg`
для расшифровки. Подготовьте отдельный Telegram-аккаунт, данные Telegram API и доступ к одному из
поддерживаемых CLI или внешнему раннеру.

```bash
git clone https://github.com/Plasmoid77/Telegram-MCP-preset
cd Telegram-MCP-preset
./install.sh
```

Следуйте [гайду по установке](docs/INSTALL.md). Введите данные Telegram API и войдите в Telegram
в своём терминале, запустите ASR и Telegram MCP, настройте идентификаторы аккаунтов и бэкенд агента,
затем запустите автоответчик. В гайде также описаны
[работа после выхода из системы и перезагрузки](docs/INSTALL.md#10-работа-без-входа-в-систему-сервер-перезагрузки)
и [удаление](docs/INSTALL.md#удаление).
Если с установкой помогает ИИ-агент, дайте ему [AGENTS.md](AGENTS.md), а секреты вводите сами.

## Бэкенды и модели

Укажите `HARNESS` (`claude`, `codex`, `opencode` или `command`) и `MODEL` в файле
`~/.local/share/telegram-agent/config.env`. Claude Code проверяет разрешения через хуки.
Codex, OpenCode и внешние раннеры используют временный локальный MCP-шлюз, который проверяет
вызовы инструментов с учётом роли собеседника и текущего чата.

В режиме OpenCode автоответчик берёт модель из `MODEL` независимо от выбора в интерактивном
`/models`. Диспетчер перечитывает файл автоматически. Перезапуск службы для смены модели
не нужен. Подробнее о [смене модели](docs/INSTALL.md#сменить-модель-автоответчика-opencode) и
[настройке бэкендов и внешних раннеров](docs/HARNESSES.md).

## Что проверено

| Окружение | Что проверили |
| --- | --- |
| **Claude Code на Arch Linux** | Личка владельца и гостя, обращения в группах и управление списком групп, сводка топика на 322 сообщения, память и ограничения guard. [Результаты](docs/PRESET.md#5-проверено-2026-11-16) |
| **CLI Codex и OpenCode** | Реальные CLI с тестовыми MCP-инструментами. Чтение и ответ в текущем чате прошли, доступ к чужому чату заблокирован. В OpenCode также проверили поиск и вызов дополнительного инструмента от имени владельца. [Интеграционные проверки](https://github.com/Plasmoid77/Telegram-MCP-preset/pull/1) |
| **OpenCode Go на LMDE 6** | Реальные ответы в личке Telegram с моделью `opencode-go/qwen3.7-plus`. Автоответчик работал как пользовательская служба systemd на домашнем сервере. |
| **Установка и удаление юнитов на LMDE 6** | Чистая установка и удаление файлов юнитов systemd проверены во временной домашней папке. [Результаты](https://github.com/Plasmoid77/Telegram-MCP-preset/pull/1) |

CI запускает ShellCheck, компиляцию Python и автоматические тесты.
Для локального запуска тестов используйте `python3 -m unittest discover -s tests`.
