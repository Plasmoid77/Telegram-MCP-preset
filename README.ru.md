# Telegram-MCP-preset

[English](README.md) · Русский

Этот пресет превращает обычный Telegram-аккаунт в ИИ-ассистента. Он отвечает в личных сообщениях
и в выбранных группах, помечает важные разговоры для владельца и выполняет его поручения
в Telegram: читает и пересказывает чаты, отвечает, пересылает сообщения, управляет папками.

Установщик загружает [chigwell/telegram-mcp](https://github.com/chigwell/telegram-mcp)
из исходного репозитория по проверенному тегу `v3.3.35`. В этом репозитории находятся
автоответчик, конфигурация сервера, локальное распознавание речи, юниты systemd и руководства.

> Используйте отдельный Telegram-аккаунт для ассистента. ИИ действует от имени этого аккаунта.

## Что умеет

- **Одна сессия Telegram, общая.** telegram-mcp обслуживает аккаунт по адресу
  `http://127.0.0.1:8765/mcp` для автоответчика и для ваших собственных MCP-клиентов.
- **Автоматические ответы.** Диспетчер отвечает на каждое личное сообщение, а в разрешённых
  группах — на ответы, @упоминания и слова-триггеры. На каждую устоявшуюся пачку сообщений
  запускается один свежий агент без интерактивного интерфейса. История чата — источник истины:
  при обрыве сети ничего не теряется, и ни на одно сообщение не отвечают дважды.
- **Владелец и гости.** В личных сообщениях владельца ассистент может использовать весь аккаунт.
  Любой другой запуск — личка гостя или группа, даже если владелец просит там, — работает
  только со своим чатом и может уведомить владельца. Ограничение действует на уровне кода,
  а не только промпта.
- **Мультимедиа и веб.** Голосовые сообщения и видеосообщения расшифровываются локально
  (onnx-asr, по умолчанию GigaAM-v3); фотографии и документы можно просматривать, видео —
  смотреть: кадры на сменах сцены и речь с метками времени на одной шкале (`view_video`);
  публичный веб-поиск (DuckDuckGo, без ключа) работает в каждом запуске с ответом, а в запусках владельца
  бот открывает ссылки (страницы и картинки; только публичные адреса и только ссылки, уже
  встреченные в переписке).
- **Пересылка.** «Пересылай, что присылает этот бот, в такую-то тему, только настоящие
  объявления, и пиши к ним короткий вердикт» — владелец настраивает это в личке; модель решает
  по каждому новому сообщению и пишет комментарий, пересылает и публикует диспетчер.
- **Память и персона.** Владелец может попросить ассистента запомнить инструкции. Персона
  по умолчанию — русскоязычный «Doom bot» в манере Джарвиса; замените её на свою `persona.md`.
- **Любой CLI-агент.** Claude Code, Codex, OpenCode или ваш собственный раннер, выбирается
  в `config.env`.
- **Обновления upstream.** Еженедельный таймер сообщает о новых релизах telegram-mcp;
  `update_mcp.py apply` обновляет с дымовым тестом и автоматическим откатом.

## Как это работает

```text
Telegram ⇄ telegram-mcp.service (one session, loopback HTTP)
             ▲ wait_for_events + history reads
             │
           telegram-agent.service (agent/dispatcher.py)
             │ one run per settled burst
             ▼
           broker (agent/broker.py, a private per-run MCP URL; checks every call)
             ▲
             │ the only MCP server the agent sees
           Claude Code │ Codex │ OpenCode │ custom runner
```

Брокер — единственное место, где принимается решение о доступе ([agent/policy.py](agent/policy.py)):
CLI-агент запускается без встроенных инструментов и без личной конфигурации и общается только с ним.
Проектирование и модель безопасности: [docs/DESIGN.md](docs/DESIGN.md).

## Быстрый старт

Linux с пользовательскими службами systemd, Python 3.10+, `git`, `uv`, `ffmpeg`; отдельный
Telegram-аккаунт с данными API; один поддерживаемый CLI-агент с выполненным входом.

```bash
git clone https://github.com/Plasmoid77/Telegram-MCP-preset ~/.local/share/telegram-agent
~/.local/share/telegram-agent/install.sh
```

Далее следуйте [docs/INSTALL.md](docs/INSTALL.md): данные Telegram и вход в собственном
терминале, `~/.config/telegram-agent/config.env`, запуск служб. Обновление существующей
установки v1: [миграция](docs/INSTALL.md#переход-с-v1). Если установке помогает ИИ-агент,
дайте ему [AGENTS.md](AGENTS.md), а секреты вводите сами.

| Где | Что |
| --- | --- |
| `~/.local/share/telegram-agent/` | этот репозиторий (код; обновление = `git checkout <tag>` + `./install.sh`) |

## Проверка

CI запускает ShellCheck, модульные тесты (политика, брокер по HTTP, адаптеры, диспетчер, скрипт
обновления, расшифровка ASR через настоящий ffmpeg, миграция v1 и её откат) и контрактный тест,
проверяющий, что каждый инструмент и аргумент, используемый пресетом, присутствует в закреплённом
релизе telegram-mcp. Локально: `python3 -m unittest discover -s tests`.

v1 этого пресета был проверен в работе с Claude Code (Arch Linux) и с OpenCode Go `qwen3.7-plus`
на домашнем сервере (LMDE 6).
